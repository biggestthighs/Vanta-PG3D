VANTA v0.1.15 preview - Windows x64

Extract the ENTIRE zip first. Keep Vanta.exe, pg3d_core.dll, offsets.json
and the models folder together.

1. Start Pixel Gun 3D and wait for its main menu.
2. Open Vanta.exe and click Load Vanta.
3. Return to the game and press INSERT.

INSERT = menu | DELETE = panic | END = unload

Farm: set kills per match, press Start farm, close the menu.
Keep the game focused. Stop farm restores your previous settings.
Custom models are experimental. See README.md for known limitations.

Source code is in source/. No developer tools are needed to run Vanta.

Open World in the in-game menu to preview and enable Aurora, Ember or Glacier.
Particles render in the scene. Map support for sky, fog and lighting varies.
The World tab shows the status of each effect.
